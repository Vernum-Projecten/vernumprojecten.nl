{# SPDX-FileCopyrightText: Vernum Projecten B.V. #} {# SPDX-License-Identifier: Apache-2.0 #} {# De Tera-componenten die de markdown in content/ en de sjablonen mogen aanroepen. Zola 0.23 kent geen shortcodes meer; een component wordt hier gedefinieerd en aangeroepen als een zelfsluitend element tussen dubbele accolades (https://www.getzola.org/documentation/content/overview/). Er zijn er twee, en dat is met opzet: hoe meer een pagina kan aanroepen, hoe minder de tekst leesbaar blijft in het bestand zelf. #} {# hoofdlink: de ene link die op een pagina telt, met de gouden lijn eronder. Goud haalt op de lichte ondergrond 3,45:1, genoeg voor een grafisch element en niet voor tekst (docs/huisstijl.md, sectie 4), dus het draagt alleen de lijn en de tekst blijft de merkkleur. #} {% component hoofdlink(pad: string, tekst: string) -%} {{ tekst }} {%- endcomponent %} {# icoon: een gevendord Lucide-bestand, in de pagina zelf gezet in plaats van als `img` geladen (static/icons/lucide/, scripts/vendor/icons.sh). Zo krijgt het de kleur van de tekst ernaast, want het bestand tekent met `currentColor`, en scheelt het een verzoek. Het pictogram staat altijd naast een woord, dus het is `aria-hidden` en een schermlezer slaat het over. #} {% component icoon(naam: string, klasse: string = "") -%} {{ load_data(path="static/icons/lucide/" ~ naam ~ ".svg", format="plain") | safe }} {%- endcomponent %}
