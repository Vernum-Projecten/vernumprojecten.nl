Deze site zet geen cookies. Er is geen statistiekendienst, geen
bezoekersteller en geen advertentienetwerk. Er staat geen JavaScript in de
pagina's, dus er valt ook niets te meten dat wij niet noemen.

Alles wat je browser ophaalt komt van dit domein: de HTML, de ene stylesheet,
de twee lettertypebestanden en de afbeeldingen. Er gaat geen verzoek naar een
lettertypedienst, een videodienst of een sociaal netwerk. Dat is te
controleren: open het netwerktabblad van je browser en kijk welke namen er
langskomen.

## Wat de hosting wel vastlegt

De site draait op GitHub Pages. GitHub legt daarbij het IP-adres van een
bezoeker vast: "When a GitHub Pages site is visited, the visitor's IP address
is logged and stored for security purposes, regardless of whether the visitor
has signed into GitHub or not"
([GitHub Docs, What is GitHub Pages, Data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)).
Wij kunnen die logboeken niet inzien en krijgen er niets uit.

Wat GitHub daarmee doet, staat in de
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
Wil je die verwerking vermijden, dan is de enige manier om deze site niet te
bezoeken. Daar zijn wij eerlijk over in plaats van er een keuzeschermpje voor
te tonen dat er niets aan verandert.

## Wat er gebeurt als je ons schrijft

Stuur je een e-mail, dan komt die in de mailbox van het bedrijf. Wij bewaren
je bericht zolang het gesprek loopt en daarna zolang we het voor onze
administratie nodig hebben. Word je klant, dan valt de bewaartermijn van de
administratie onder de wettelijke termijn van zeven jaar
([artikel 52 Algemene wet inzake rijksbelastingen](https://wetten.overheid.nl/BWBR0002320)).
Word je geen klant, dan verdwijnt het bericht daarna.

Je gegevens gaan niet naar een andere partij, worden niet verkocht en worden
niet gebruikt om je iets toe te sturen waar je niet om vroeg.

## Je rechten

Je mag opvragen welke gegevens wij van je hebben, ze laten verbeteren of laten
wissen. Schrijf daarvoor naar het adres op de pagina
[Contact](@/contact.md). Kom je er met ons niet uit, dan kun je klagen bij de
[Autoriteit Persoonsgegevens](https://autoriteitpersoonsgegevens.nl/).
